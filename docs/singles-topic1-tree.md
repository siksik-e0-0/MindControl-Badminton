## 전제
- 나 = 서버, 상대 = 리시버. 둘 다 오른손. 점수 짝수라 오른쪽 코트에서 서브.
- 코트는 단식 선(안쪽 옆선, 뒤는 끝선까지). 급수 4단계(D·C·B·A) 공통, 비율은 전부 추정.
- 복식과 같은 깊이: 0 서브 → 1 상대 리턴 → 2 내 3구(기술 → 코스) → 3 마지막 장면(결과 판정과 다음 예상).
- 표의 '비중'은 갈래가 뽑히는 상대 크기(1~4, 클수록 자주). '급수 방향' −1은 낮은 급수일수록 많이, +1은 높은 급수일수록 많이 고른다는 뜻(기존 복식 표와 같은 방식). 화면에는 급수별 %로 나온다.
- 남녀 구분 없음(사용자 결정 2026-09-24: 라벨 '단식').

## 0 서브 — 하이 서브, 중앙 깊게
- 위치: 나는 숏서비스라인 약 1 m 뒤, 센터라인 옆. 상대는 대각선 코트, 서비스라인 약 1.5 m 뒤.
- 샷: 하이 서브 → 상대 코트 뒤 중앙(끝선 가까이).
- 설명
  - 기본: 하이 서브는 중앙으로. 코너로 보내면 상대 각이 넓어진다. [BB 단식 서브·BB 중앙]
  - 조건: 상대 스매시가 강하거나 드롭 속임이 좋으면 하이 서브를 줄이고 로우 서브. [BB 단식 서브]
  - 이동: 친 뒤 베이스로. 정중앙보다 살짝 뒤(리프트와 같은 원리). [BB 베이스 + 추정]
  - 규칙: 단식 서비스 코트는 좁고 길다 — 안쪽 옆선 안, 뒤는 끝선까지. [BWF 규칙]
  - 위험: 짧은 하이 서브는 점프 스매시를 맞는다. [BB 클리어(얕은 공) + 추정]

## 1 상대 리턴 — 4갈래(코스 9)
비율은 급수별 추정.

```
갈래            비중 급수방향 코스(비중)                                근거
클리어          4   −1    내 백핸드 뒤 3 · 포핸드 뒤 2 · 중앙 깊게 2   BI 리시브(전 급수), BB 클리어(스트레이트 기본·백핸드 쪽 효과)
드롭(빠른)      4   +1    스트레이트(내 백핸드 앞) 3 · 크로스 2        BI 리시브(프로 남 56%·여 47%), BB 드롭(거의 다 빠른 드롭)
스매시          2   +1    사이드 스트레이트 3 · 몸 2 · 크로스 1        BB 스매시(사이드가 기본·직선이 안전), BB 단식 서브(강타자 주의)
스트레이트 슬라이스 1 +1  내 앞쪽에 짧게 1                            BI 리시브(고급) → B조 이상만(D·C조 '불가')
```
- 화면 설명: 상황 "하이 서브가 깊으면 상대는 뒤에서 친다 — 클리어·드롭이 대부분, 스매시는 서브가 짧을 때." 면 "상대는 포핸드 오버헤드(중앙 뒤, 오른손 기준)."
- 새 규칙 하나: 갈래에 최소 급수(minTier)를 둘 수 있게 함. 그 급수 미만이면 '불가'로 표시(기존 잠금 표시 그대로).

## 2 내 3구 — 들어온 공마다 기술 → 코스
면(포핸드/백핸드)과 높이는 복식과 같은 방식으로 판정·잠금.

### 2a 상대 클리어가 내 백핸드 뒤 코너 (백핸드 오버헤드)
```
기술            비중 급수방향 코스                         근거·잠금
클리어          4   −1    스트레이트 · 상대 백핸드(크로스) · 중앙(수비)   BB 클리어: 대부분 스트레이트, 백핸드 쪽은 크로스 위험 상쇄, 수비면 최대 높이 중앙
빠른 드롭       3    0    스트레이트 · 크로스           BB 드롭: 스트레이트가 안전, 크로스 클리어 뒤엔 스트레이트 드롭
공격 클리어     1   +1    스트레이트                    BB 클리어: 상대가 늦었을 때, 얕으면 가로채기
스매시          2   +1    사이드 · 몸                   D조 백핸드 오버헤드 스매시 불가(기존 표)
```
- 이동: 클리어·드롭 뒤 베이스는 뒤로, 친 쪽으로 치우침. [BB 베이스]
- 위험: 백핸드 뒤에서 크로스 클리어가 짧으면 직선 스매시. [BB 클리어]

### 2b 상대 클리어가 내 포핸드 뒤 코너 / 중앙 깊게 (포핸드 오버헤드)
- 2a와 같은 기술. 스매시 w 3(포핸드라 잠금 없음). 중앙에서는 "각이 좁으니 코너로 되돌려 흔든다". [BB 코너·BB 중앙]

### 2c 상대 드롭이 내 앞 (백핸드 앞 / 포핸드 앞, 낮은 공)
```
기술            비중 급수방향 코스                         근거·잠금
네트샷(타이트)  4    0    스트레이트                    BB 네트샷: 대부분 스트레이트, 타이트하면 짧은 리프트를 강요
리프트          4   −1    상대 백핸드 뒤(코너) · 중앙 높게   BB 리프트: 백핸드 쪽 유효, 몰리면 중앙 높게; 네트샷 뒤 상대가 붙었으면 낮게
크로스 네트샷   1   +1    크로스                        BB 네트샷: 스핀 못 씀, 직선 응수에 열림
푸시/드라이브   1   +1    상대 몸                       네트 위에서 잡았을 때만(조건). 추정
```
- 이동: 네트샷 뒤 베이스는 앞으로 치우침. [BB 베이스]
- 목적: 타이트 네트샷 → 짧은 리프트 → 스매시 기회. [BB 네트샷]

### 2d 상대 스매시 (스트레이트 / 몸 / 크로스)
```
기술            비중 급수방향 코스                         근거·잠금
블록(네트)      4   −1    스트레이트 · 크로스           BB 스매시 수비: 가장 쉽고 상대를 앞으로 끌어냄. 크로스 스매시엔 스트레이트 블록, 직선 스매시엔 크로스 블록
리프트          3    0    중앙 높게 · 낮게(기습)        BB 스매시 수비: 몰리면 높게 중앙, 상대가 앞으로 나올 때 낮게
드라이브 카운터 2   +1    빈 쪽(직선 스매시면 크로스)   BB 스매시 수비: 신중히. D조 백핸드 드라이브 불가(기존 표)
롱 블록         1    0    크로스                        BB 스매시 수비: 직선 스매시 뒤 크로스 롱 블록만 예외
```
- 위험: 직선 스매시가 가장 받기 어렵다 — 리프트한 쪽으로 베이스 치우침. [BI 단식 수비]
- 기본: 라켓은 무릎 높이, 상대 타격 직전 스플릿 스텝. [BI 단식 수비]

### 2e 상대 슬라이스 (내 앞쪽에 짧게, 낮게 받음)
- 네트샷 3 · 리프트 4(중앙 높게 / 코너). [BI 리시브: 낮게 받아 선택지가 적다]
